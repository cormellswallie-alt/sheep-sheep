# 羊了个羊 · 复刻版

一个画面精致的「羊了个羊」玩法复刻，Android 原生壳 + Canvas 渲染，零第三方依赖。

## 玩法（与原版一致）
- 点击**未被遮挡**的牌放入底部 **7 格卡槽**，三张相同自动消除
- 卡槽塞满 7 张即失败；清空全部牌即通关「加入羊群」
- 同类牌入槽时自动靠拢排列
- 每关道具各 1 次：**移出**（槽内前 3 张移到上方暂存区）、**撤回**（退回上一步）、**洗牌**（打乱场上图案）
- 失败后可**复活 1 次**（移出 3 张）

## v1.1 新功能
- **今日挑战**：按日期生成种子，所有人当天玩同一副牌；首次通关必得稀有及以上小羊
- **关卡码**：每局都有关卡码（如 `2-K7Q3MZ`），暂停/失败界面可复制、分享，输入关卡码即可复现同一牌局
- **看看正解**：失败后可自动回放生成器记录的通关路线（1×/2×/4× 倍速）；看过答案的牌局不再发放小羊
- **羊圈收集**：通关领养随机小羊（普通/稀有/史诗/传说：毛色、配饰、黑羊、金羊、彩虹羊），在羊圈里溜达吃草，点击查看档案
- **画面升级**：牌面材质与高光、抛物线飞牌、三连聚合后爆开、连消提示、粒子与彩带、飘落花瓣、木质卡槽与满槽警示、首页远山与太阳光芒

## 难度复刻
| 关卡 | 牌数 | 图案 | 结构 |
|---|---|---|---|
| 第 1 关 | 27 | 3 种 | 3 层，新手教学 |
| 第 2 关 | ~290 | 16 种 | 9 层半格错位叠放 + 左右两组盲牌堆（只露最上面一张） |
| 第 3 关+ | 300+ | 17~20 种 | 层数、盲牌递增 |

关卡采用「逆向生成」：先随机模拟一条合法拆牌顺序，再在 3 组三连的窗口内打乱分配图案，
因此**每局必定存在解**，但贪心策略模拟（`tools/sim.js`）通关率为 0%，平均只能清掉 ~45% —— 和原版一样“差一点”。
